### Lire / Modifier

### Étapes
1. Cœur : N0 par `node .claude/workflow/bin/n0.mjs` ; N1 ; bilan ; commit ; incident ; statut ;
   **push** (C3 : `pull --rebase` puis `push`, sauf `wave.lock` ou sous-agent orchestré ; N0 rouge
   à l'interruption → branche `wip/P<n>-S<k>`). Plus de lancement de revue par la session.

   geste `git merge-base --is-ancestor` côté session suivante. Reste le **domicile** de la règle :
   vérifier que les renvois des autres skills (`cadrer`, `orchestrer-plan`) pointent le nouveau chemin.

   même commit, plus de repère `Revues:`) ; le point 8b (dépôt source) y descend.

   source charge son plugin par une installation **locale** qui copie `plugin/` dans le cache
   (`CLAUDE.md`, « Règles spécifiques ») ; sans cette mise à jour, il continue de dérouler la
   version d'avant le bump (constat du 2026-09-17).
4. `vague-parallele.md` : le mode sous verrou, tel quel.

### Validation

- **Anti-raccourci** : une annexe jamais citée depuis le cœur n'est jamais lue — chaque
