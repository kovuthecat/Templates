Sans lui, le plan repose sur quatre prémisses comportementales non vérifiées.

une contrainte d'outillage) : dire exactement quoi faire et quoi lire à l'écran.

   affiche sur sa ligne ; supprimer l'agent. — seul `/tasks` montre l'effort réel.
2. **B** — recherche d'outils `start_session`, `hand_off_to_session` ; noter présents/absents et,
   si présents, leur schéma (paramètres modèle, effort, dossier, prompt). Ne rien démarrer.
3. **C** — demander à l'utilisateur d'ouvrir une session cloud sur un dépôt vendoré de test, d'y
   lire si le bloc « règles communes injectées » apparaît, et d'y tenter `git push origin HEAD:main`
   d'un commit vide sur un dépôt **jetable**. Noter les deux constats.
4. **D** — sans objet tant que `SubagentStop` n'est pas câblé : noter « non sondée, sans
   conséquence sur P6 ».
