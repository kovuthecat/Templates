### Décision clé
D-P2-3. `hooks.json` reproduit EXACTEMENT le câblage de `project-settings.json` (SessionStart /
PreToolUse Bash|PowerShell / Stop, mêmes timeouts) en remplaçant les chemins absolus par
`${CLAUDE_PLUGIN_ROOT}/.claude/hooks/<fichier>.mjs`. Le hook format est silencieux et sans échec :
pas de prettier configuré dans le projet → exit 0 sans sortie ; erreur prettier → ne JAMAIS bloquer
(le format est un confort, pas une gate).
