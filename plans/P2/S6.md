## T15 — `nouveau-plan` : Plan Mode, tests, lancement, orchestrateur, /goal

### Objectif
Le cadrage se lance en Plan Mode, chaque tâche a une ligne tests, chaque session une commande de
lancement, les vagues sans N1 peuvent tourner en headless.

être justifié. Orchestrateur : `claude -p` = processus Claude Code neuf sans interface, contexte
vierge à chaque session ; limites à écrire noir sur blanc : permissions en allowlist requises
(pas d'humain pour confirmer) et PAS de navigateur in-app → toute session `Env. Desktop` est
exclue de l'orchestration.

### Lire / Modifier

1. Étape 1 (Investiguer) : ajouter en tête « Se mettre en **Plan Mode** pour toute l'investigation —
   le mode interdit l'écriture, la consigne "jamais modifier" devient structurelle. »
   Mentionner les agents du plugin : exploration → `explorateur`, résumé de diff → `resumeur-git`.
2. Squelette S<k>, bandeau : ajouter la ligne
   `> **Lancement : \`claude --model <modèle>\` · effort : /effort si ≠ défaut · autonome : /goal « toutes les tâches de ce fichier faites, N0 vert »**`.
3. Squelette S<k>, bloc Validation : ajouter la ligne
   `- **Tests** : <créés/mis à jour : fichiers, cas couverts> — ou « — » justifié en 1 ligne`.
4. Étape 3 (index), après Ordonnancement : ajouter 4-6 lignes « **Vagues autonomes (optionnel)** —

   --model <modèle>` séquentiellement (parallèle : uniquement zones disjointes + `wave.lock`
   posé), ne garde que les verdicts, s'arrête au premier FAIL. Prérequis : allowlist de
   permissions dans `.claude/settings.json`. »
