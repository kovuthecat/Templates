## T12 — Quatre mesures que le cadrage n'a pas pu faire

### Objectif
Mesurer, dans ce dépôt (`.git` désormais dossier) :
- **M1 — preuve N0 après fusion** : dans un worktree créé par `git worktree add -b sonde/s-a <tmp> HEAD`,
  un commit de tâche factice portant `Plan: PSONDE/S1/T1`, puis `n0.mjs --session PSONDE/S1` (fiche
  factice minimale dans le worktree), commit de la preuve ; fusion `git merge --no-ff` dans
  `sonde/p21-worktree` avec un message **sans** `Plan:` (`Fusion PSONDE/S1`) ; `preuve-n0.mjs` vérifie la
  preuve depuis `sonde/p21-worktree`. Puis la même fusion avec un message qui porte `Plan: PSONDE/S1/` :
  la vérification casse-t-elle (critique du plan, constat 6) ?
- **M2 — deux copies, fichiers de suivi** : deux worktrees qui modifient chacun **sa** ligne voisine
  d'un `index.md` factice et le même `STATUS.md` factice → la fusion de la seconde est-elle en conflit ?
  Puis la même chose sans toucher `index.md` ni `STATUS.md` → fusion propre ? (constat 2 de la critique). Positif : conflit dans le premier cas, fusion propre dans le second (la règle « la session ne coche pas » de S7 suffit). Négatif : conflit même sans fichiers de suivi → S7 doit fusionner autrement, l'écrire.
- **M3 — réinstallation des dépendances** : sur un clone local jetable (`git clone <projet>`, dans le
  dossier temporaire du système) d'un projet Node de `C:/Users/Kovu/Projets` qui a un `package-lock.json`,
  temps et taille de `npm ci` dans un worktree de ce clone ; comparer à la même commande dans le clone. Positif : `npm ci` aboutit dans la copie, coût chiffré (annoncé à l'utilisateur en S9). Négatif : échec dans la copie (chemin, verrou, lien) → l'écrire avec l'erreur ; S7 doit alors repasser en série les projets à dépendances.
- **M4 — réveil d'une session qui délègue** : la session elle-même, avant de déléguer, committe dans
  l'analyse la ligne « M4 : réveil NON constaté (écrit avant délégation, <heure>) » ; puis lance un agent
  `explorateur` sur une question courte ; si elle reçoit la notification de fin, elle réécrit la ligne
  (« réveil constaté, <heure>, <délai> ») et committe. Une ligne restée « NON constaté » est le résultat.

### Pourquoi
Le cadrage a établi que la copie isolée se crée, part du HEAD local, garde sa branche et ses commits
après la fin de l'agent, et que nos hooks y acceptent un commit. Restent les mesures dont S7 dépend pour
la collecte (M1, M2), le coût annoncé à l'utilisateur (M3), et la réécriture de la règle « premier plan »
en S6 (M4).

### Décision clé
- M1 réfutée **avec** un message de fusion sans `Plan:` → `FAIL` nature `prémisse` : la collecte
  décidée (fusion sans réécriture) ne garde pas la preuve vérifiable, le plan s'arrête.
- M1 réfutée seulement avec `Plan:` dans le message : c'est la contrainte de format à transmettre à S7,
  pas un échec.
- M2, M3, M4 : mesures, jamais un `FAIL` — leur résultat oriente S6 et S7.
