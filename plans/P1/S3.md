## T5 — Jonction NTFS : skill fin-de-tache au niveau utilisateur

### Objectif

`~/.claude/skills/fin-de-tache` disponible dans tous les projets, source unique versionnée
dans Templates.

### Décision clé

Jonction NTFS (pas de droits admin requis), cible = le dossier de la skill dans Templates.

### Lire / Modifier

- Créer : jonction `~/.claude/skills/fin-de-tache`

### Étapes

1. `New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude\skills"` (si absent).
2. Si `$env:USERPROFILE\.claude\skills\fin-de-tache` existe déjà (copie) : la supprimer.
3. `New-Item -ItemType Junction -Path "$env:USERPROFILE\.claude\skills\fin-de-tache" -Target "C:\Users\kovu\SynologyDrive\Thibault\Projets\Templates\.claude\skills\fin-de-tache"`
4. Vérifier : `Get-Content "$env:USERPROFILE\.claude\skills\fin-de-tache\SKILL.md" -TotalCount 5`
   affiche le frontmatter de la skill.

### Validation

- Auto : la commande de l'étape 4 renvoie le contenu attendu.

### Si bloqué

La jonction échoue (droits, Synology Drive) → repli : copie simple du dossier + noter dans le
rapport qu'une re-copie manuelle sera nécessaire à chaque évolution de la skill.

### Lire / Modifier

1. Dérouler la skill `update-config` pour ajouter à `permissions.allow` :
   `Read(C:/Users/kovu/SynologyDrive/Thibault/Projets/Templates/**)`
   (slashes avant, format glob des règles de permission).
