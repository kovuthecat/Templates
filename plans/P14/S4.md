## T8 — Fichier de mesures, vérification, report sur `main`

### Objectif
Écrire `docs/analyses/2026-10-06-reglage-sessions-planifiees-mesures.md`, vérifier que le poste est
revenu à son état d'avant, puis reporter ce seul fichier sur `main`.

### Pourquoi
C'est la seule trace qui survit à la branche : la décision d'intégration (`/orchestrer-plan`,
`WORKFLOW.md` §5b) se prendra sur `main` en le lisant, et il doit dire quelle voie retenir.

### Décision clé
- **Contenu** (décision, « Ce qui revient ») : en tête, « Ce que ça change, en clair » (la voie
  retenue et ce que l'utilisateur verra) ; puis l'écart Opus · low et sa preuve ; puis une section
  par mesure — `## Étape 0`, `## B`, `## C1`, `## C2` — avec le protocole tel qu'exécuté, les
  lignes de transcription citées, la commande qui reproduit (`preuves/reglage/transcription.mjs`)
  et le verdict contre le critère **cité mot pour mot** (ligne `**Verdict :`) ; puis `## Réfuté`,
  `## Voie retenue` (B, C ou repli A), `## Gestes humains` (cible : 0), `## Défauts relevés`
  (outillage du workflow vu en route).
- Une mesure non jouée (C1, C2 quand B est positive) a sa section : « non jouée : <motif> ».
- **Report sur `main` par un index temporaire, sans `switch`** (procédure de P13/S7) :
  ```
  git fetch origin main
  export GIT_INDEX_FILE="$(mktemp)"
  git read-tree origin/main
  git update-index --add --cacheinfo 100644,"$(git hash-object -w docs/analyses/2026-10-06-reglage-sessions-planifiees-mesures.md)",docs/analyses/2026-10-06-reglage-sessions-planifiees-mesures.md
  arbre="$(git write-tree)"; unset GIT_INDEX_FILE
  c="$(git commit-tree "$arbre" -p origin/main -F <fichier de message>)"
  git push origin "$c:refs/heads/main"
  ```
  Message : `docs(preuve): mesures du réglage des sessions planifiées (P14)`, une ligne
  `Déroulé sur preuve/reglage-session : statuts, preuves N0 et revues y restent.`, puis la ligne
  `Co-Authored-By` d'usage. Pas de repère `Plan:` sur `main`.
